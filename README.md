# Perfil Edición · landing

Página estática de @perfil_edicion: recursos gratis para editores de video y lista de espera de la comunidad.

- Sin build ni dependencias: se publica tal cual (Vercel, carpeta raíz).
- Los enlaces (Drive, lista de espera, TikTok) y el video de la portada se cambian en las primeras líneas de `main.js`.
- El dominio para las vistas previas al compartir está en `index.html` (`canonical`, `og:url`, `og:image`).
